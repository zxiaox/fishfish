# Three Doors sound pack

The spoken prompts are AI-generated English speech from HeyGen, created for this game using public catalog voices. They are not recordings by human actors or clones of the reference-video subject. Each named voice has a separate "Please choose a door" recording and a separate recording for each of the three possible eliminated doors.

- Host 1: Janet, voice ID `4270665fc47f44aa989c093bb3dc2b99`.
- Host 2: Joanna, voice ID `776f9d2ff401499a8f1f2bcb4ca46004`.
- Host 3: Roderic, voice ID `b5c5b28db1ea408abc7d851202983bdb`.
- Provider-returned engine: `orca`. Files were converted from the returned MP3 audio to mono 22.05 kHz 16-bit PCM WAV for offline Windows playback, without changing the playback speed.
- The short success and failure tones were generated locally for this project.

The voice prompts say “Please choose a door.” and “I have eliminated door 1/2/3 for you; would you like to switch doors?” The interface supports seven languages; the bundled voice pack is English only. Sound can be switched off in Settings.
